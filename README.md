# MKT Skills — Shopify VA

An independent toolkit by Vince Servidad, not affiliated with or endorsed by Shopify.

**MKT Skills — Shopify VA** (`mkt-skills-shopify-va`, version `0.2.2`) provides 19 read-only Markdown skill workflows for Shopify virtual assistants and specialists across research, listings, catalogs, merchandising, orders, audits, CRO, SEO, ads, email, support, automation, theme guidance, and analytics.

The plugin contains instruction files and reference material only. It runs no server, sets no hooks, collects no telemetry, and requires no store credentials for public research or work from supplied files.

## Start read-only

Provide your task, target store context, supplied evidence, acceptance criteria, and exact permission level. Unknown commercial or product facts remain unknown; drafts, recommendations, and live changes stay under human review and owner approval.

## Skill catalog

Choose the skill that owns the deliverable. Use `shopify-va` for mixed tasks and add specialists only for distinct decisions.
