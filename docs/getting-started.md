# Getting Started

Use [the usage guide](../USAGE.md) for installation, your first assignment, and
troubleshooting. This page is a short route to the supporting references.

## 1. Choose one owner skill

Use the [19-skill catalog](../README.md#skill-catalog), or the coordinator's
[task routing](../skills/shopify-va/references/task-routing.md) for mixed work.

## 2. Supply business context

Complete the relevant fields in the [business context template](business-context-template.md).

## 3. State the authorization boundary

Name read-only, draft-only, save-inactive, or exact approved implementation scope.
See [evidence and authorization](evidence-and-authorization.md) for the rules.

## 4. Attach source-of-truth evidence

Follow the usage guide's [evidence checklist](../USAGE.md#what-evidence-should-you-provide).
Keep credentials and unnecessary personal data out of supplied files.

## 5. Ask for an evidence-led output

Use the [request structure](../USAGE.md#recommended-request-structure) or a
job-specific example from the [prompt library](prompt-library.md).

## 6. Review before implementation

Check sources, unknowns, guardrails, and the scoped approval under
[evidence and authorization](evidence-and-authorization.md).

## 7. Verify the terminal state

Reopen the authoritative target after an approved action. Use the
[operating checklist](../skills/shopify-va/references/operating-checklists.md)
to record actual state, evidence, exceptions, and the next owner.
