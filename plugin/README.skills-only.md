# ShopifySkills

An independent toolkit by Vince Servidad with 19 Shopify workflow skills for
merchants, VAs, freelancers, agencies, developers, marketers and store
specialists. Not affiliated with or endorsed by Shopify.

This portable package contains instructions, references and synthetic teaching
assets. It does not connect to Shopify, read a store, grant permissions, or
perform live changes. Supply relevant exports or source material, avoid secrets
and unnecessary customer data, and state the exact authorization boundary.

Install this plugin once through a host that supports its native plugin format.
Then select **ShopifySkills** in that host's plugin picker and ask in plain
language, for example: “Research this product opportunity using public sources.”
An `@` mention is available only where the host exposes installed plugins that way.
Research uses the host's available search tools or supplied evidence; the plugin
does not add a search engine or require Shopify sign-in.

The package includes native Codex, Claude-compatible, and portable manifests
for the same 19 workflows. It has no MCP server, credential requirement, or
background process. It does not register itself in a curated app directory;
installation and directory publication are separate actions.

Start with: “Use shopify-va to route this task. Keep the work read-only, separate
facts from assumptions, and flag the evidence needed before any live change.”

For a local read-only Shopify connection or a separately hosted OAuth connector,
use the setup guide in the source repository:
https://github.com/vinceservidad/Shopify-Expert-AI-Skills
