# Creative Testing Framework

## Diagnosis dimensions

Review performance by concept, message, hook, format, creator or presenter, proof, visual mechanism, offer, placement, audience, landing page, and time. Do not attribute the result to one dimension when several changed together.

## Test question

```yaml
decision:
learning_question:
unit_of_comparison:
controlled_elements:
changed_elements:
eligible_delivery:
primary_business_outcome:
leading_indicators:
commercial_guardrail:
quality_checks:
minimum_evidence:
stop:
```

Set minimum evidence from account volume, decision risk, and the testing method. Do not encode a universal spend or conversion threshold.

## Learning log

Record the hypothesis, delivery context, dates, asset versions, outcome definitions, result, guardrails, uncertainty, decision, and next question. A pattern is scoped learning, not universal causality.
