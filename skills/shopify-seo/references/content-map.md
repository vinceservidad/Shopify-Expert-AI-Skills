# Shopify SEO Content Map

## Architecture

```text
Brand or homepage
  -> Commercial collections
      -> Products
      -> Selection and comparison guides
  -> Educational hubs
      -> Focused guides
      -> Relevant collections and products
  -> Support and policy content
```

Use the smallest architecture that covers real customer tasks. Do not create empty hubs or thin pages only to match a keyword list.

## Technical map

Track template, canonical, index directive, status code, internal-link depth, sitemap state, alternate-language handling, structured data, and rendering dependencies for each important page type.

## Internal-link rules

- link where it helps the user's next decision
- use descriptive anchors without forced exact-match repetition
- avoid links to unavailable, redirected, non-canonical, or irrelevant pages
- preserve links that carry navigation, authority, or conversion value unless a better destination is verified
- update links when consolidating or redirecting content

## Release verification

After approved publication, verify the canonical live page, rendered metadata and content, status and redirect behavior, internal links, structured data validity, sitemap inclusion when appropriate, and Search Console discovery or index state over time. Publication does not guarantee crawling, indexation, ranking, traffic, or revenue.
